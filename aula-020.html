02 — ADJECTIVES

New vs. Old

Usamos New para coisas novas e Old para coisas velhas ou antigas. Para seres vivos (como árvores), o oposto de Old costuma ser Young.

This is an old car.
Este é um carro velho.
This is a new bike.
Esta é uma bicicleta nova.
DICA DE COMPARAÇÃO ✓ Old tree / Young tree (Árvore velha / jovem)
✓ Old car / New car (Carro velho / novo)
O sentido de "idade" é o mesmo, mas as palavras mudam conforme o objeto.
03 — POSSESSION

The 's Rule

Para indicar que algo pertence a alguém, usamos o 's após o nome da pessoa.

It's Jenna's car.
É o carro da Jenna.
It's Jax's skateboard.
É o skate do Jax.
04 — GRAMMAR

There are

The plural of "There is"

EXISTÊNCIA (PLURAL) ✓ There are two men in the house.
✗ There is two men in the house.
Use There is para singular (há/tem um) e There are para plural (há/tem vários).
05 — QUANTITY

A lot of

🌳 A lot of...

Muitos / Grande quantidade
Pronúncia conectada: "A lóra"

Usamos para indicar uma grande quantidade de algo, como em uma floresta ou cidade grande.

There are a lot of trees in a forest.
Há muitas árvores em uma floresta.
There are a lot of dogs in New York.
Há muitos cachorros em Nova York.
