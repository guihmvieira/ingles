02 — KEY PHRASES

Perguntas e Respostas

Como perguntar o nome e a origem de alguém de forma natural.

What's your name?
Qual é o seu nome?
My name's Matheus.
Meu nome é Matheus.
Where are you from?
De onde você é?
I'm from Brazil.
Eu sou do Brasil.
03 — GRAMMAR RULE

The vs A

ESPECÍFICO VS. GERAL ✓ I'm the teacher (Sou o único professor aqui)
✓ You're a student (Você é um entre vários alunos)
Use "the" para algo único ou específico. Use "a" para algo que é um entre muitos.
04 — NATIONALITY

País vs. Nacionalidade

🇧🇷 Brazilian

I'm Brazilian
Pronúncia: /bra-zi-li-an/

Cuidado para não confundir: Brazil é o país (country), enquanto Brazilian é a nacionalidade (nationality).

05 — PRACTICE

Quem é você?

Who are you?
Quem é você?
✓ I'm [Seu Nome]
✗ My name Matheus
Lembre-se sempre de usar o verbo (is/'s ou am/'m). Nunca diga apenas "My name [Nome]".
